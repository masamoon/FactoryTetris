# Short-form product constraint: independent adversarial review

20 September 2026. Documentation and product-direction review only; no runtime rule was changed.

## Initial proposal

The initial wording required every design and gameplay decision to serve an appealing 30-second mobile clip, allowing abridged or real-time footage and using viral mobile games as the comparison frame.

**Initial verdict: REVISE.** Literal adoption would reward footage over the game. It could favor shallow but spectacular upgrades, hide recurring maintenance outside the edit, make necessary recovery/accessibility work appear valueless and import deceptive playable-ad conventions. The current real replay reaches its first part after 39.3 simulation seconds without human planning time, so it cannot honestly be presented as a complete new-player factory build inside 30 seconds.

## Component verdicts

| Component                                       | Initial verdict              | Required revision                                                                                                                                                            |
| ----------------------------------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Thirty-second clipability as product north star | **REVISE**                   | Use it as a product-direction and communication gate paired with ordinary-play depth, mobile usability and truthful pacing.                                                  |
| Abridged footage                                | **REVISE**                   | Disclose prepared saves, cuts, speed changes and compressed waits; preserve causality, costs, rates and failure states; retain an uncut witness.                             |
| Every decision individually serves clipability  | **REJECT**                   | Use a portfolio-level rule: a decision may create the hook, improve readability, preserve truth, support recovery/accessibility or provide the durable game behind the clip. |
| Viral mobile games as comparison frame          | **REVISE**                   | Restrict references to portrait framing, silent legibility, visual hierarchy and action-to-payoff cadence. Virality is not product evidence.                                 |
| Truthful-clip review gate                       | **PASS after specification** | Record starting state, action and consequence, capture mode, uncut witness, phone readability, representativeness and an ordinary-play companion review.                     |

## Concrete failure cases

- A recurring reach purchase can keep a drill moving attractively while reducing progression to a compulsory stat ladder.
- A tender can create an impressive extension animation while removing meaningful mining-front choices.
- A prepared backlog can create a dramatic burst without improving sustained throughput.
- An edit can omit exhaustion seconds later and falsely imply permanent automation.
- Speed-ramping cargo can misrepresent capacity and production rate.
- Mature footage can be mistaken for onboarding if its prepared starting state is hidden.
- Enlarged effects can obscure starvation, blockage and machine state on the actual phone interface.
- Optimizing everything for immediate readability can favor mandatory interruptions and obvious repairs over planning, ownership and long-term agency.

## Revised adoption

The resubmitted rule adopted the portfolio-level wording, disclosed abridgement with an uncut witness, comparison references limited to presentation/cadence and a clip verdict limited to the communication hypothesis. It also added an eight-point design gate and required an ordinary-play companion review.

**Final verdict: PASS.** No documentation blocker remained. The PASS does not establish enjoyment, balance, retention, virality or commercial viability.
